# Infotact-Project-2
**SaaS Cohort Retention & Customer Lifetime Value (CLTV) Analysis**
#Project Overview
This project analyzes customer acquisition, subscription revenue, churn behaviour, customer lifetime value (CLTV), and cohort retention for a SaaS business.
A synthetic subscription dataset representing 2,500 B2B SaaS customers over an 18-month period was generated to simulate real-world subscription analytics.
An interactive Tableau dashboard was also built to visualize key business metrics.
#Business Objectives
- Analyze customer acquisition channels
- Measure Monthly Recurring Revenue (MRR)
- Calculate Customer Lifetime Value (CLTV)
- Analyze churn behaviour
- Perform Cohort Retention Analysis
- Build an executive Tableau Dashboard
#Dataset Overview
The dataset contains:
- Customer ID
- Signup Date
- Billing Date
- Plan Tier
- Monthly Recurring Revenue
- Acquisition Channel
- Industry
- Company Size
- Subscription Events
- Cancellation Reason

- # Key Business Insights
- High-performing acquisition channels generated stronger recurring revenue.
- Premium subscription plans significantly increased MRR.
- Certain industries consistently generated higher revenue.
- Larger organizations contributed higher recurring revenue.
- Churn analysis highlighted major customer pain points.
- CLTV provided a benchmark for sustainable customer acquisition investment.
- Cohort retention analysis revealed customer behaviour across time and identified periods of highest customer drop-off.
